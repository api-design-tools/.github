# API Design Tools

Open-source tools and practical standards for designing, linting, and governing REST and OpenAPI contracts in CI/CD.

## Featured Project

- **[api-design-principles](https://github.com/api-design-tools/api-design-principles)** ([Live Browser Validator](https://api-design-tools.github.io/api-design-principles/)) — 32 standards-backed API design rules (`RFC 9110`, `RFC 9457`, `RFC 8594`, `IETF Idempotency-Key`, `OWASP API Top 10`), zero-dependency JSON & YAML OpenAPI validator, breaking-change diff (`--diff`), industry presets, and GitHub Action with SARIF 2.1.0 output.
